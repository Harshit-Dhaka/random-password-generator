Random Password Generator
A lightweight, responsive web application built with JavaScript, HTML, and CSS that generates secure, customizable random passwords with one-click clipboard copying.

Features
Custom password length configuration

Dual password generation for easy comparison

One-click copy-to-clipboard functionality

Clean, dark-themed UI

What I Learned

DOM Manipulation: Selecting elements using document.getElementById() and dynamically updating text content with .textContent.

Event Listeners: Handling user interactions using .addEventListener() for button clicks and clipboard copy triggers.

JavaScript Fundamentals:

Working with arrays and generating pseudo-random indices using Math.random() and Math.floor().

Using for loops to iterate and build strings based on user-defined lengths.

Browser APIs: Integrating the Clipboard API (navigator.clipboard.writeText()) to copy text directly to the user's clipboard.

CSS Styling: Structuring layouts using margins, custom color palettes, and interactive button states.
